# myBucket - Your Personalised To-Do List

**myBucket** is a simple, intuitive, and personalized to-do list web application designed to help you organize your daily tasks efficiently. Built using core web technologies, myBucket focuses on ease of use, clean design, and essential task management features, making it perfect for students, professionals, and anyone looking to boost productivity.

## Project Overview

myBucket provides a straightforward interface for adding, viewing, and managing your daily tasks. Its minimalist design ensures that you can focus on what matters most—getting things done. The application is fully client-side, requiring no backend or database setup.

---

## Features

- **Add Tasks:**  
  Quickly add new tasks to your to-do list with a simple input form.

- **View Tasks:**  
  See all your tasks in a clear, organized list.

- **Mark as Complete:**  
  Check off tasks as you complete them to keep track of your progress.

- **Delete Tasks:**  
  Remove tasks from your list when they're no longer needed.

- **Persistent Storage:**  
  Tasks are saved in your browser's local storage, so your list remains even after refreshing or closing the browser.

- **Minimalist & Responsive Design:**  
  Clean interface that works well on both desktop and mobile devices.

---

## Technology Stack

- **HTML5** — Structure and layout
- **CSS3** — Styling and responsive design
- **JavaScript (ES6+)** — Task management logic and local storage

## Getting Started

1. **Clone the repository:**
    ```
    git clone https://github.com/harshitkowsik/myBucket.git
    cd myBucket
    ```

2. **Open the Application:**
    - Open `index.html` in your preferred web browser.

3. **Start Managing Your Tasks:**
    - Add, complete, and delete tasks as needed.

---

## How It Works

- **Adding a Task:**  
  Enter your task in the input field and press the add button. The task will appear in your list.

- **Completing a Task:**  
  Click the checkbox or the task itself (depending on implementation) to mark it as completed.

- **Deleting a Task:**  
  Click the delete icon/button next to a task to remove it from your list.

- **Persistence:**  
  All tasks are stored in your browser's local storage, so your list is saved automatically.
